# FDE.AI Phase 1 开发拆分总览

> 版本：v0.1
> 目标：将 Phase 1 拆成可由 Coding Agent 分多次执行的开发任务。
> 单次代码变更约束：**每个任务的实现代码新增/修改尽量控制在 1000 行以内**。超过范围必须拆任务，不得为了完成任务而大范围重构。

## 1. 第一阶段最终能力

```text
Plugin Runtime
    ↓
Observation
    ↓
Agent Event
    ↓
Memory
    ↓
Memory Revision / Diff
    ↓
Timeline

同时提供：
Plugin Management
Memory Viewer
Timeline Viewer
```

Phase 1 的目标不是完成 FDE 自动化，而是建立可运行、可观察、可调试的 Runtime。

## 2. 开发任务总表

| 编号 | 文档 | 目标 | 前置 | 建议代码变更 |
|---|---|---|---|---:|
| 01 | Runtime Core | Plugin Manifest / Registry / Lifecycle | 无 | ≤ 700 行 |
| 02 | Event & Observation | EventBus、Observation 模型与持久化 | 01 | ≤ 800 行 |
| 03 | Memory Core | Memory、Revision、Diff、Memory Service | 02 | ≤ 900 行 |
| 04 | Timeline Query API | 统一事件查询与时间线 API | 02、03 | ≤ 700 行 |
| 05 | Plugin Management API | Plugin 列表、详情、启停 | 01 | ≤ 700 行 |
| 06 | Console Shell & Plugin UI | Console 基础壳与 Plugin 页面 | 04、05 | ≤ 900 行 |
| 07 | Memory UI | Memory 列表、详情、历史 Diff | 03、04 | ≤ 800 行 |
| 08 | Timeline UI | 时间线、过滤、事件详情 | 04、06 | ≤ 900 行 |
| 09 | E2E Demo & Hardening | 打通最小闭环、补充测试和开发体验 | 01-08 | ≤ 900 行 |

## 3. 推荐执行顺序

```text
01 Runtime Core
   ↓
02 Event & Observation
   ↓
03 Memory Core
   ↓
┌───────────────┬──────────────┐
↓               ↓              ↓
04 Timeline API  05 Plugin API  
└───────┬───────┴───────┬──────┘
        ↓               ↓
06 Console + Plugin UI  
        ↓
07 Memory UI
        ↓
08 Timeline UI
        ↓
09 E2E Demo & Hardening
```

04 与 05 在基础完成后可以并行；06 依赖两者。

## 4. 每次 Coding Agent 的统一执行规则

1. 先阅读仓库现有结构，不假设项目技术栈；优先复用现有目录、依赖和命名。
2. 只实现本任务中列出的目标；禁止顺手重构、换框架、升级无关依赖。
3. 代码修改尽量 ≤ 1000 行；本任务设置的目标预算更低时，以本任务预算为准。
4. 不修改下一任务负责的核心模块，除非为接口兼容所必需。
5. 新增公共接口时必须添加最小单元测试或类型检查。
6. 不实现尚未进入 Phase 1 的能力，如自动化执行、复杂 Agent Loop、完整多租户权限、Plugin Marketplace。
7. 如现有代码与本文档冲突，以“保持现有可运行性 + 最小修改”为优先，并在最终输出说明冲突点。

## 5. 最小闭环验收

最终应可完成：

```text
Mock / Test Plugin
  ↓
emit Observation
  ↓
Event Store
  ↓
Agent Event
  ↓
Memory Service
  ↓
Memory Revision
  ↓
Timeline API
  ↓
Console Timeline
```

并可看到：
- Observation 来自哪个 Plugin。
- Observation 发生时间。
- Agent 对其做了什么处理。
- 哪个 Memory 被改变。
- Memory before / after / diff。
- Plugin 是否 Enabled。
